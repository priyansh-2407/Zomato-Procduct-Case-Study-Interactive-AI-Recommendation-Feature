Contribution Margin by Segment

Discount Dependency vs Retention

How It Works

  • 1. User selects a mood/intent (11 options)
  • 2. Optionally fine-tunes with budget, cuisine, ETA, diet, distance
  • 3. Recommendation engine generates personalized results
  • 4. Each result explains WHY it was recommended
  • 5. User feedback improves future recommendations

Edge Cases Handled

New User

No history → Use location, popular restaurants, stated preferences, context

New Restaurant

No order data → Use quality, availability, cuisine match, exploration slots

No Preference

Everything neutral → Use contextual signals (time, location, trending)

Wants Something New

Exploration mode → Increase novelty weight, suppress frequently ordered

Algorithm Fairness & Diversity

Diversity Constraint

Top 5 results cannot all be the same cuisine, restaurant chain, or price segment. This prevents filter bubbles and ensures restaurant fairness.

Exploration Slots

10-15% of recommendation slots are reserved for new or underrepresented restaurants, preventing popularity bias and enabling restaurant discovery.

Feedback Loop Prevention

Exposure caps limit maximum impressions per restaurant. We monitor HHI (Herfindahl-Hirschman Index) of order concentration as a guardrail metric.
